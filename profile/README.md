# Git for Scientists

Git for Scientists is an Open Educational Resource: a hands-on workshop that teaches researchers the foundations of Git and GitHub for collaboration in scientific work. The course has changed with each iteration. The table below shows how.

The instructor handbook documents the pedagogy, setup, and run of show of the four-hour course in RStudio, so that an educator who was not in the room can teach the workshop from checklists.

- Website and instructor handbook: <https://gitforsci.github.io/website/>
- Source repository: [gitforsci/website](https://github.com/gitforsci/website)
- Template development: [gitforsci-dev](https://github.com/gitforsci-dev)

## Iterations

Each workshop iteration runs in its own GitHub organisation, started from the templates in [gitforsci-dev](https://github.com/gitforsci-dev) and adapted to the audience.

| Iteration | Organisation | Website | Taught | Format | DOI |
|---|---|---|---|---|---|
| ETH Zurich CIS retreat | [gitforsci-cis](https://github.com/gitforsci-cis) | <https://gitforsci-cis.github.io/website/> | 27 May 2025 | Two hours, RStudio | cites canonical |
| Global Health Engineering, ETH Zurich | [gitforsci-ghe](https://github.com/gitforsci-ghe) | <https://gitforsci-ghe.github.io/website/> | 15 July 2026 | Four hours, RStudio and terminal | [10.5281/zenodo.21704114](https://doi.org/10.5281/zenodo.21704114) |
| Research Data Conference 2026, Bern | [gitforsci-rdc](https://github.com/gitforsci-rdc) | <https://gitforsci-rdc.github.io/website/> | 20 November 2026 | Two hours, GitHub Desktop, with a part for educators | cites canonical |

What each iteration taught:

- **CIS retreat:** two hours were not enough time for the content.
- **Global Health Engineering:** RStudio, Quarto and the installation of an R package added overhead that the basics of Git and GitHub do not need.
- **Research Data Conference 2026:** the basics are taught in two hours again, with GitHub Desktop. A second session of two hours is new, with `.gitignore`, collaboration, and task and project management.
